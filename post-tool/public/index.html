Google投稿コンテンツ生成ツール Four Seasons

1. 店舗を選ぶ

複数選ぶと、同じテーマを店舗ごとに一括生成します（同じ顧客の店舗のみ）。

2. 投稿内容を入力

案の数
〜 CSV出力

左の一覧から顧客・ブランド・店舗を選ぶか、新規登録してください。

CSV出力

Excel で開ける UTF-8（BOM付き）CSV です。

顧客 ブランド 店舗 メニュー・商品 投稿案

CSV一括登録

出力したCSVと同じ列で取り込みます。id が空欄の行は新規登録、id がある行は更新します。1行でもエラーがあれば全件取り消します。登録順は 顧客 → ブランド → 店舗 → メニュー です。


      
バックアップ

      
全データ（変更履歴を含む）を JSON で保存します。サーバー側では npm run backup でデータベースファイルを日時付きで複製できます。
