# ゆめつぼ様 Instagram運用 実務マニュアル（8章）
第2版：2026年11月21日｜対象：本部・校舎の運用担当｜作成：Four Seasons

この資料は、3か月の伴走で決めたことと、実際に作った投稿・テンプレートをもとにまとめた運用の手引きです。［　］の部分は本部で決めて書き込んでください。

## 第1章 発信方針・トーン

**発信の目的**：ゆめつぼの教育方針とレッスンの場面を正しく伝え、関心を持った保護者が該当校の最新情報に迷わずたどり着けるようにする。

**4つの投稿テーマ（発信の軸）**

| テーマ | 中身 | 主な形式 |
|---|---|---|
| ① 夢中な表情 | こどもだけで段取り・調理するレッスン風景 | リール、工程カルーセル、今日の一枚 |
| ② 成長ストーリー | 会員さまの声・卒業生の活躍・ビフォーアフターで「変化」を伝える | 保護者の声、卒業生の活躍、あのころ→いま |
| ③ 食育のまめ知識 | 保存される役立ち投稿 | 食材図鑑、クイズ、おうちでできるチェックリスト |
| ④ 体験レッスン案内 | 日程・空き状況を統一フォーマットで告知 | 体験告知、教室紹介、よくある質問 |

月12本（フィード8・リール4）が目安。季節の行事（クリスマス、年末年始、節分、新学期）に合わせて話題を選ぶ。

**基本トーン**：温かく、具体的で、押しつけない。こどもを「できない／できる」で評価せず、本人の工夫や挑戦を描く。保護者に不安や罪悪感を与えない。

**書かないこと**：成長・学力・健康効果の保証、根拠のない「日本一」「No.1」、確認していない料金・対象・空き情報、掲載の許可がないエピソード。栄養の専門的な説明は、監修者の確認がとれたものだけ。

**キャプションの型**（11月〜1月の36本で使った型）

1. 1行目：投稿の見出し（画像の1枚目と同じ言葉）
2. 場面・エピソード（2〜4行）
3. 保護者の言葉は「　」で原文のまま
4. 必要に応じて「※ご家族の許可をいただいて掲載しています。」
5. 最後に「▶ 教室のことは、プロフィールのリンクから」
6. ハッシュタグ（下の基本セット）

**ハッシュタグの基本セット**：#こどもだけの料理教室 #ゆめつぼ #こども料理教室 #キッズキッチン #食育 #こどもの習い事 #習い事 #茨木市 #大阪 #料理好きな子（校舎の投稿は地域名を差し替える。季節の投稿は1〜2個足す）

## 第2章 撮影ガイド

**撮影の基本**：写真は縦（4:5）、動画は縦（9:16）で撮る。窓際などの自然光で、背景を整える。手元・材料・完成品の寄りと、教室全体の引きを混ぜる。

**1回のレッスンで撮りたいカット**：材料／レシピを読む手元／計量・下ごしらえ／先生が見守る場面／調理の安全な工程／盛り付け／完成した料理を持つ姿／片付け。

**動画のコツ**：1本を短く（10〜20秒）区切って撮る。長い動画は容量が大きくなり、共有や編集がしにくくなる。

**写さないもの**：名札、学校名、住所・電話番号が入ったチラシ、個人の持ち物の名前。写ってしまった場合は投稿前にぼかす（第5章）。

**撮影しない状況**：掲載の可否がわからない、体調不良や配慮が必要、危険な工程。レッスンの妨げにならない範囲で撮る。

**ファイル名**：日付_校舎_テーマ_連番（例：20261120_堀江校_手元_01）。こどもの名前はファイル名に入れない。

**共有フォルダ**：「嶋野様SNS共有フォルダ」の構成（ロゴ／写真・動画＞教室の様子・卒業生の活躍・会員様の声）に、月ごとのフォルダを足して入れる。

## 第3章 投稿の作り方

1. 投稿計画で、テーマ・形式・校舎・投稿日を確認する。
2. 使う写真の掲載可否と、名札・名前の写り込みを確認する。
3. 1投稿で伝えることを1つに決める。申込の案内は1か所だけ。
4. フィードは1枚目で内容がわかる短い見出しにする。複数枚なら1枚1要点、最後は締めのページ（プロフィールへの誘導）。
5. リールは最初の1〜2秒に見どころを置く。テロップは2行まで。音はInstagram内の音源を使う。
6. キャプションは第1章の型で書く。校舎情報には確認日を入れる。
7. 確認者［　］の承認をもらってから投稿する。
8. 投稿後、投稿URLと数字を記録する（第8章）。

## 第4章 Canvaの使い方

**テンプレート12個**（どれも実際の写真・文章入りの見本を兼ねる。Canvaの無料プランだけで編集・書き出しできる）

| テーマ | テンプレート |
|---|---|
| ① 夢中な表情 | 1-A リール（写真つなぎ）／1-B レッスン工程カルーセル／1-C 今日の一枚 |
| ② 成長ストーリー | 2-A 保護者の声カルーセル／2-B 卒業生の活躍カルーセル／2-C あのころ→いま |
| ③ 食育のまめ知識 | 3-A 食材図鑑／3-B クイズ（Q→A）／3-C おうちでできるチェックリスト |
| ④ 体験レッスン案内 | 4-A 体験レッスン告知／4-B 教室紹介／4-C よくある質問 |

**使い方**

1. 使うテンプレートを開き、「ファイル」→「コピーを作成」で複製する（元のテンプレートは上書きしない）。
2. 名前を「年月_投稿番号_テーマ」に変える（例：202602_01_夢中な表情）。
3. 写真の枠に、新しい写真をドラッグして差し替える。位置はダブルクリックで調整できる。
4. 文字をダブルクリックして書き換える。長くなる時は文字の大きさを少し下げるか、2枚に分ける。
5. 「共有」→「ダウンロード」で書き出す。フィードはPNG、リール（1-A）はMP4。

**リールの作り方（1-A）**：ページごとに写真とテロップを差し替え、各ページの表示時間（2〜3秒）を決めて、MP4でダウンロードする。音はInstagramで投稿する時に付ける。

**デザインのきまり**：色は赤（#DA3349）を基調に、生成り（#FBF6EC）、緑（#6EA028）、青（#56AAD0）をアクセントに使う。ロゴ・講師キャラ・食材イラストは本部提供のもの。Canvaの有料素材（王冠マークの付いた素材）は使わない。

**部品置き場**：レイアウトのマスター（11種）は、新しい形式を作りたい時のために残しておく。

## 第5章 写真掲載・個人情報・権利

こどもの写真・名前は慎重に扱う。撮影の許可と、SNSに載せる許可は別物として確認する。

**これまでのルール**

- 本部の共有フォルダに入れた写真は、SNSに使ってよいと本部と合意している。
- こどもの名前はイニシャルで書く（例：小学2年生 T.Sちゃん）。
- 保護者の言葉は原文のまま引用し、文中のこどもの名前は「娘」「息子」などに置き換える。
- 名札、手書きの名前（レシピの紙・お皿など）、LINE画面の名前、チラシの電話番号は、投稿前にぼかす。
- 成人の卒業生（講師など）は、顔とエピソードの掲載を本人にも確認する。

**掲載前の確認**：許可の範囲（顔・後ろ姿・手元・音声）／校舎の承認／削除を頼まれた時の連絡先［　］。

**素材の権利**：保護者から届いた写真・口コミ画像、レシピ、イラスト、BGMの利用条件を記録する。第三者のSNS投稿を勝手に転載しない。

**誤って載せた時**：すぐ本部責任者［　］に連絡し、非公開・削除の判断を受ける。対象URL、時刻、原因、再発防止を記録する。保護者への連絡は責任者が行う。

## 第6章 コメント・DM対応

**毎営業日確認する**：質問、申込希望、苦情、安全・個人情報に関する投稿。

- 場所・日程など確定している情報：公式の最新案内を見て返信する。
- 個別の空き・申込：該当校につなぐ。SNS上で個人情報を聞かない。
- 料理・栄養・健康の専門的な質問：担当者に確認してから答える。効果を断定しない。
- 苦情・事故・個人情報・報道：公開の場でやりとりしない。画面と日時を保存し、本部責任者へすぐ共有する。独断で削除・反論しない。

**返信例**：「お問い合わせありがとうございます。校舎・日程によりご案内が異なるため、ご希望の教室名をお知らせいただけましたら、最新の情報をご案内します。お名前やご連絡先は、申込フォームからお送りください。」

**返信の目安**：一次確認［　］時間以内／担当不在時の代わり［　］。

## 第7章 体験申込への導線

**流れ**：投稿 → プロフィール → 体験申込ページ（校舎を選べる）→ 校舎からの連絡

1. 投稿する前に、対象校・日程・対象年齢・料金・残席を校舎担当が確認する。
2. 投稿とプロフィールのリンク先で同じ情報を出す。
3. 申込フォームをスマートフォンで試す（開く→校舎を選ぶ→送信→完了画面）。
4. 案内は1つに絞る。空き状況が変わったら、すぐ投稿・ストーリーズを直す。
5. 個人情報はDMで集めず、申込フォームで受け取る。

**プロフィールの整え方（案）**

- 名前欄：こどもだけの料理教室 ゆめつぼ｜こども料理教室
- プロフィール文：こどもだけで、段取りから調理・片付けまで／少人数制｜先生は手を出さずに見守ります／［校舎一覧］／▼体験レッスンはこちら
- リンク：体験申込ページを1つ［URL］
- 固定投稿：こどもだけで、ここまでつくる／卒業生の活躍No.1／体験レッスンのご案内
- ハイライト（表紙画像は納品済み）：はじめての方へ／レッスン／保護者の声／卒業生／体験・教室／よくある質問

**募集情報の確認票**：校舎［　］／確認者［　］／確認日［　］／対象［　］／日程［　］／料金［　］／残席［　］／申込URL［　］

## 第8章 振り返り・改善

月に1回、「結果 → 理由の仮説 → 次の一手」を1つずつ記録する。リーチだけで良し悪しを決めない。

**投稿ごとに記録する数字**：テーマ、形式、投稿日、リーチ、保存、シェア、コメント、プロフィールへのアクセス、リンクのタップ、問い合わせ・体験申込（わかる範囲）。

**比べ方**：テーマ別・形式別に比べる。投稿数や時期の違いも書き添える。申込が数えられない時は「計測できていない」と書く。

**改善のヒント**

- リーチは多いが保存が少ない：役立つ要点やまとめ方を工夫する（③食育の形式を試す）。
- 保存は多いがプロフィールに来ない：投稿の最後で教室とのつながりを伝える。
- プロフィールには来るが申込がない：リンク先の校舎選び・日程の見やすさを確認する。
- リールが見られるが途中で離れる：冒頭の見どころと長さ、テロップの量を見直す。

いずれも仮説なので、1本の投稿だけで決めつけない。
