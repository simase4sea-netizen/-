# Brainコンテンツ企画・執筆ツール（brain-studio）

Brainで販売する有料コンテンツを、**企画 → 執筆 → 販売ページ作成 → 書き出し**まで進めるための個人用Webアプリです。
AIで似た記事を大量に出すためのものではなく、ユーザーが入力した実体験・数値・判断基準をもとに、読者の課題ごとに異なる商品を企画・作成することを目的にしています。

> **重要な前提**
> - 生成物はすべて**下書き**です。内容・表現・根拠をご自身で確認・編集してから販売してください。
> - **Brainへの自動投稿・自動出品は行いません。** 書き出したファイルやコピーした文章を、ご自身でBrainに登録してください。
> - 本ツールは販売数・売上・収益を保証しません。
> - 入力していない実績・顧客名・売上・フォロワー増加数・お客様の声は生成しない設計です（生成AIの指示と画面の両方で制御）。根拠が足りない箇所は「【要確認】」と表示されます。

---

## 必要な環境

- Node.js 20 以上（動作確認：22）
- npm

## セットアップと起動

```bash
cd brain-studio
npm install

# 開発モード（http://localhost:3000）
npm run dev

# または本番ビルドで起動
npm run build
npm start
```

ブラウザで http://localhost:3000 を開きます。初回起動時にサンプル企画3件が作られます（「【サンプル】」付き。1件目と2件目は重複警告の確認用に意図的に似せてあります）。

## Anthropic APIキーの設定

生成AIはサーバー側（Next.jsのAPIルート）から Anthropic API を呼び出します。APIキーはブラウザ・書き出しファイル・ログには出しません。

1. `.env.example` を `.env.local` にコピーします。
2. `ANTHROPIC_API_KEY=` の後ろにAPIキーを書きます。
3. アプリを再起動します。

```bash
cp .env.example .env.local
# .env.local を編集
ANTHROPIC_API_KEY=sk-ant-...
```

任意の環境変数：

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | 使用モデル |
| `ANTHROPIC_EFFORT` | `medium` | 推論の深さ（`low` / `medium` / `high`）。`low` にすると料金と待ち時間が減ります |
| `BRAIN_STUDIO_DATA_DIR` | `./data` | データ保存先ディレクトリ |

API呼び出しでは、モデルの安全判定で依頼が断られた場合に別モデルで再試行するサーバー側フォールバック（`fallbacks: "default"`）を有効にしています。

### デモモード

APIキーが未設定の場合、生成ボタンは**定型のデモ出力**を返します（実績・数値は含みません）。画面操作の確認に使えます。APIキーがあっても、設定画面の「デモ出力で動かす」でデモモードにできます。画面右上のバッジで現在の状態を確認できます。

## データの保存場所と外部送信

- 入力内容・生成物・履歴は、**このPC内のJSONファイル**（既定：`brain-studio/data/store.json`）に保存されます。設定画面に実際のパスが表示されます。
- `data/` は `.gitignore` 済みです。バックアップは設定画面の「全データをJSONでバックアップ」か、ライブラリの書き出しを使ってください。
- 外部へ送信されるのは、**APIを使った生成時のリクエストだけ**です。送信前に確認ダイアログで送信内容を表示します（同じタブでは次回から省略可能）。
- 「新規企画」画面の入力途中の内容と未保存の候補だけは、ブラウザの localStorage に一時保存されます。

## 使い方の流れ

1. **設定**：発信者のプロフィール・判断基準・テーマ候補を確認・編集します（嶋野成優さんの情報は初期表示用の仮設定で、編集・削除できます）。
2. **事例・根拠**：本文で使ってよい実体験を「事例名／対象期間／実施内容／ユーザーが入力した結果／出典・メモ／確認日」で登録します。登録していない事例は使われません。
3. **新規企画**：読者・課題・判断基準・使用する事例・禁止表現・形式・生成数（1〜30件）を入力し、まず**企画案だけ**を作ります。
   - 指定件数を「1回あたりの生成数」ごとに分け、1回ずつ順番に処理します（進捗表示・停止・失敗/停止分だけ再試行）。
   - APIキー未設定や利用上限エラーのときは、残りのリクエストを自動で止めます。
   - 候補ごとに重複チェック結果が表示されます。良いものだけを選んでライブラリに保存します。
4. **ライブラリ**：検索、テーマ・状態・類似警告での絞り込み、複製、編集、削除（確認あり）、複数選択でのZIP書き出し、選択した企画の基本設計の順次生成ができます。
5. **編集画面**：次の順にセクションごとに生成・編集します。
   1. 商品の基本設計 2. 目次と章構成 3. 有料本文（章ごと） 4. 購入前の無料部分 5. 販売ページ下書き 6. 特典・実務素材 7. 告知文
   - 内容があるセクションの再生成は確認を出し、結果を「生成候補」として表示します（置き換え／末尾に追加／破棄）。置き換えても元の内容は履歴に残ります。
   - 編集は自動保存されます（画面右上に保存状態を表示）。履歴から任意の版、または「直前の内容へ戻す」で復元できます。
   - 本文は章ごとに生成・保存・再生成します。「未執筆の章を順番に生成」も使えます。
6. **品質確認**：7項目のチェック、確認メモ、ローカル自動チェック、AIによる参考評価（API使用時は料金が発生）を確認し、**最終確認者の名前を入力して承認**します。自動チェックやAI評価で「承認済み」になることはありません。
7. **書き出し**：Markdown・TXT・JSON・CSV・ZIPで書き出します。承認済みの企画を書き出すと「書き出し済み」になります。

## 書き出し形式

| 形式 | 内容 |
|---|---|
| Markdown（Brain貼り付け用） | 無料部分 →「ここから有料部分」→ 本文 → 特典 |
| Markdown（セクション別） | `00_企画概要.md`（使用した事例・対象期間・承認者を含む）、`01_無料部分.md`、`02_有料本文.md`、`03_販売ページ.md`、`04_告知文.md`、`05_特典素材.md`、`06_基本設計と目次.md` |
| TXT | 全セクションを見出し記号なしのテキストに変換 |
| JSON | 企画・全セクション・履歴・使用事例のバックアップ（ライブラリの「JSONバックアップを読み込む」で復元可能） |
| CSV | 企画一覧（Excelで開けるようBOM付きUTF-8） |
| ZIP | 選択した複数企画を、企画ごとのフォルダ（上記MD・TXT・JSON）と `企画一覧.csv` にまとめたもの |

文字コードはすべてUTF-8、ZIP内のファイル名もUTF-8フラグ付きで格納しています。

## 独自性・品質管理の仕組み

- **類似チェック（ローカル・API不使用）**：日本語を文字2-gram/3-gramに分け、TF-IDFのコサイン類似度で次の3つを比較します。
  - タイトル＋想定読者 / 解決する課題＋到達目標 / 目次＋本文
  - しきい値は `src/lib/similarity.ts` の `THRESHOLDS`。「重複の疑い」「類似あり」を表示し、統合・差別化・削除の提案を出します。
- **表現チェック（ローカル）**：「必ず成功」「誰でも簡単」「売上…保証」「月収○○」などの成果保証・煽り表現を検出します（否定文・注意書きの行は除外）。`src/lib/checks.ts`
- **【要確認】の集計**：根拠が不足している箇所の数を、カード・品質確認・書き出し画面に表示します。
- **生成時のルール**：事実／経験則／仮説／一般的な説明のラベル付け、入力されていない実績・数値・体験談の禁止、出典のない統計やプラットフォーム仕様の断定禁止などをシステムプロンプトで指示しています。`src/lib/server/prompts.ts`
- ダッシュボードでは企画の合計数とは別に、要確認・承認済みの数を表示します。

## ディレクトリ構成

```
src/
  app/                  画面（ダッシュボード / new / library / projects/[id] / cases / settings）
  app/api/              サーバー側API（データ保存・生成）
  components/           共通UI、編集画面のタブ、生成キュー
  lib/                  データモデル、類似度、表現チェック、書き出し、ZIP、デモ出力
  lib/server/           ファイル保存、Anthropic API呼び出し、プロンプト
data/store.json         保存データ（自動作成・git管理外）
```

## 既知の制約

- 個人がローカルで使う前提です。認証はありません。インターネットに公開しないでください。
- 類似チェックは文字の重なりによる判定のため、言い回しが違っても意味が同じ企画は検出できないことがあります。逆に、同じテーマの語句を多く含む企画は類似と判定されやすくなります。
- AI生成の品質・正確性は保証されません。プラットフォームの仕様や最新ルールは、必ず公式情報で確認してください。
- 生成の途中経過（ストリーミング）は画面に表示せず、完了後にまとめて表示します。長い章は完了まで1〜数分かかることがあります。
- 同じ企画を複数のタブで同時に編集すると、後から保存した内容で上書きされます。
- Linux環境でロケールがUTF-8でない場合、ブラウザによっては日本語のダウンロードファイル名が `download` になることがあります（内容はUTF-8で正しく保存されます）。
- APIキーを使った実際の生成は、開発環境にAPIキーがないため未検証です（APIキー無効時のエラー処理と、デモモードでの全機能は検証済み）。
