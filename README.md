# Four Seasons 業務アシスト

合同会社Four Seasons の事務作業（広告報告・会議後のタスク整理・インフルエンサー選定・請求・Google投稿作成）を効率化するためのツールです。
情報の整理・計算・下書き作成までを自動化し、**送信・公開は必ず人が確認・承認してから手動で行う**設計です。

> リポジトリ直下の `index.html` は別資料（パートナープログラムのページ）です。業務アシストは `app/` にあります。

## 使い始め方

1. `app/index.html` をブラウザ（Chrome / Edge / Safari）で開く（ダブルクリックで開けます。サーバー不要）
2. 画面左下（スマホは上部）の「利用者」が自分になっているか確認する
3. ホームの「サンプルデータで試す」で動作を確認する
4. 「店舗・案件」で顧客店舗を登録する（自社店舗 3 店舗は登録済み）

データはそのブラウザ内に保存されます。端末を変える前や定期的に「設定 → バックアップを書き出す」を行ってください。

## できること（第1段階）

| 機能 | 内容 |
|---|---|
| 広告レポート作成 | 手入力／CSV（Meta広告マネージャ等）／表の貼り付け／画像を見ながら転記 → 指標計算（計算式付き）→ 前回比（前回値がある場合のみ）→ 所見案・改善案 → 店舗向け報告文 → 要確認事項 |
| 議事録・タスク整理 | 文字起こし・メモ → 決定／未決／共有／タスクに分類 → タスクを Four Seasons側・店舗側・その他に分け、担当者・期限・必要な素材を付与（不明は「未設定」）→ 重複タスクの統合 |
| タスク一覧 | 全議事録のタスクを期限順に表示。期限超過・3日以内を強調。未設定のものを抽出。CSV書き出し |
| 店舗・案件管理 | 自社店舗／顧客案件の区分、別名、店舗ごとの報告文の形式 |
| 承認フロー | 下書き → 確認待ち → 承認済み → 完了。承認・コピー・完了の前に確認画面 |
| 操作履歴 | 誰が・いつ・何を作成・編集・承認したかを記録 |

## グルメインフルエンサー候補選定（第2段階で追加）

| 機能 | 内容 |
|---|---|
| キャンペーン条件 | 店舗・所在地・来店可能エリア・ジャンル・目的・希望SNS／投稿形式・無料招待／有償・予算・提供内容・投稿条件など |
| 候補者の登録 | **URLを一括登録**（貼り付けたプロフィールURLを読み取り、重複・投稿URLを除いて登録し、公式APIで数値を自動取得）、手動登録、検索結果のURLをまとめて登録（検索場所・検索語・検索日を出典として保存）、CSV一括登録。数値ごとに「確認済み／推定／未確認」・取得元・確認日・確認者を記録 |
| 重複検出 | 同じプロフィールURL（表記ゆれを正規化）は登録不可。同一人物の別SNSアカウントは関連付けて表示 |
| 評価 | 地域・ジャンル・反応・品質・キャンペーン適合・費用の6観点。未確認は0点にせず計算から外し、情報が少なければ「判定材料不足」。理由・懸念点・追加確認事項を表示。重みは設定画面で変更可 |
| 一覧・比較 | 絞り込み（地域・駅名・料理・ハッシュタグ・地域適合・ジャンル適合・目的適合など）、複数候補の横並び比較 |
| 出力 | 提案リストをCSV・PDF（印刷画面）で出力。承認前は「下書き・社内検討用」と表示 |
| 連絡・起用管理 | 11段階の起用状況と変更履歴。連絡文の下書き → 承認 → コピー → 担当者が手動で送信。**DM・メールの自動送信はしません** |

**自動選定**：設定画面でYouTube Data APIキー（とInstagramのアクセストークン）を入れると、地域・フォロワー数・ジャンルの3条件で候補を自動で探し、優先候補・候補に振り分け、連絡文の下書きまで自動で作ります（TikTokは公式APIの制約で自動検索不可。送信は承認後に手動）。

詳しくは [docs/インフルエンサー候補選定_設計.md](docs/インフルエンサー候補選定_設計.md)。外部API（Instagram・TikTok・YouTube）は未連携です（調査結果と連携方針は同ドキュメント）。

## 請求管理・請求書作成（第3段階で追加）

| 機能 | 内容 |
|---|---|
| 請求先・契約 | 1社に複数店舗・案件を紐づけ。月額／単発、値引き・追加料金・初期費用、前払い期間、日割り、請求停止・契約終了・料金変更を履歴付きで管理 |
| 請求書の作成 | 契約から明細を作成（複数月の一括も可）、手入力の単発・追加作業・値引き、定期請求のまとめ作成 |
| チェック | 未設定（料金・税区分・端数処理・登録番号など）は確定不可。二重請求・期間外・請求停止・前払い重複は警告し、理由を記録するまで承認不可。請求漏れを一覧表示 |
| 承認・発行 | 下書き → 確認待ち → 承認済み → 発行済み（番号確定）。取消・再発行は理由必須。発行済みの請求書は契約・設定を変えても変わらない |
| 入金 | 手動登録・CSV取込、残額の自動計算、一部入金・期限超過の一覧、催促文（承認後にコピー） |
| 出力 | 請求書の表示・PDF（印刷画面）、請求一覧・明細・入金一覧・会計取込用（汎用）のCSV。保存先フォルダ指定（上書きしない） |

**メールの送信・会計ソフトへの自動連携は行いません。** 端数処理・税率・適格請求書の扱いは初期値を決めていないため、「請求管理の設定」で確認のうえ設定してください。詳しくは [docs/請求管理_設計.md](docs/請求管理_設計.md)。

## Google投稿作成（第4段階で追加）

登録済みの店舗情報から、Googleビジネスプロフィール投稿用の **画像用キャッチコピー・日本語投稿文・英語投稿文** を1セットで作ります。サーバー版（ブランチ `claude/busy-einstein-7jf1ce` の `post-tool/`）の仕様・判定ロジックを、業務アシストの作り（サーバー不要・localStorage 保存・承認フロー）に合わせて書き直したものです。文章ルールは [docs/google-post-rules.md](docs/google-post-rules.md)（同ブランチ）に従います。

| 画面（左メニュー「Google投稿」） | できること |
|---|---|
| Google投稿作成 | 店舗を選ぶ（複数で一括生成）→ 投稿内容を入力 → 生成前の確認（食い違いの選択・不足情報）→ 生成 → 編集・保存・複製 |
| 投稿案一覧 | 店舗・テーマ・作成日・状態・キーワードで検索、詳細で確認待ち → 承認 → コピー（4種類）→ 投稿済み・完了。CSV出力 |
| 店舗情報・ブランド | ブランド共通の情報、店舗ごとのGoogle投稿用の情報・使用できるCTA・メニュー、CSVでの一括登録・出力 |
| Google仕様設定 | 本文上限などの仕様値・確認日・出典を編集（変えるとチェックにすぐ反映）。変更履歴つき |

- **データの持たせ方**：店舗ごとの情報とメニューは既存の `stores[].gpost` に追加し、ブランド共通の情報は `gpost.brands` に置いて店舗から `brandId` で参照します。既存の店舗データには区分（自社店舗／顧客案件）しかなく、「案件」は店舗ごと、「請求先」は請求のためのデータで目的が違うため、共有用のブランドを別に持たせました。自社店舗と顧客案件で同じブランドは使えません。
- **優先順位**：店舗の情報とブランドの情報が違う場合は店舗を優先。文章トーンは「投稿入力 → 店舗 → ブランド」。
- **生成**：1店舗ずつ、その店舗の登録情報と投稿入力だけで事実シートを作って生成します（他店舗の情報は入れません）。一括生成は、同じ区分で、顧客案件は同じブランドの店舗だけ。APIキーが無いときは **デモ生成（テンプレート）** で動作し、画面に明示します。AI生成（Claude `claude-opus-5-5`、構造化出力）は確認画面でチェックを入れたときだけ送信します。
- **自動チェック**（担当者向け確認欄。コピーには含みません）：Google上限（日本語・英語それぞれ）、電話番号、未登録の数値・URL、英語版だけの数値、他店舗の店名・住所・予約URL・メニュー名、季節表現、見出し、キャッチコピーと本文の一致、抽象的な褒め言葉、避けたい表現。保存のたびに再チェックし、エラーが残ったまま承認しようとすると確認が出ます。
- **承認とコピー**：既存の承認ルールどおり、承認済みになるまでコピーできません。
- **Google仕様**：値はコード（`app/js/core/gpost.js`）に書かず、初期値を `app/config/google-spec.default.js` に置き、画面で編集します。初期値は公式ヘルプを引用した二次情報で確認したもので **「要再確認」** です（開発環境から support.google.com・developers.google.com に接続できず、公式ページでの確認はできていません）。運用前に公式ページで確認し、確認日を更新してください。
- **Googleへの自動投稿は行いません**（外部へ投稿する処理そのものを持っていません）。

### 取り違え・誤記の防止

- 作業中の店舗名と区分（自社店舗／顧客案件）を画面上部に常に表示
- 対象店舗の変更時、CSV取り込み時、承認時、コピー時に店舗名を表示して確認
- CSVのキャンペーン名や報告文に**別の店舗名**が含まれていると警告
- 報告文中の数値が入力値・計算結果と**一致しない**と警告（手で書き換えた場合の転記ミス対策）
- 未入力の値は推測で埋めず、報告文に `【要確認：〇〇未入力】` として残す

## 手動で行う作業

- 店舗への送信（承認後に「送信用にコピー」→ LINE・メール等に貼り付けて送信 →「完了」で記録）
- 音声の文字起こし（会議ツールやスマートフォンの機能でテキスト化してから貼り付け）
- 広告管理画面からのCSV書き出し・スクリーンショット
- バックアップの書き出し

## 承認が必要な操作

外部へ出すもの（店舗への報告文、共有用の議事録、Google投稿文）はすべて「承認済み」になるまでコピーできません。
このツール自体は外部送信・SNS投稿・広告配信・予約投稿・契約確定・請求確定を一切行いません。

## AI読み取り（任意）

設定で Anthropic API キーを登録すると、画像からの数値読み取り・議事録の整理・Google投稿文の生成に Claude（`claude-opus-5-5`）を使えます。
- 使うたびに外部送信の確認画面が出ます
- 結果はすべて「要確認」の下書きとして入力欄に入ります
- 議事録では、メモ本文に根拠の無い担当者・期限は採用しません
- 無効のままでも全機能を手入力・CSV・ルール抽出で使えます

## 未対応（今後追加予定）

Instagram・YouTube の公式API連携（インフルエンサー候補の数値取得）／SNS投稿・LINE配信文の作成／案件・撮影・投稿の進行管理／Googleマップの口コミ返信／店舗運営文書、
各種サービス（Meta広告・Instagram・LINE・Googleビジネスプロフィール）との自動連携、複数端末でのデータ共有。
