# Google投稿文の生成ルール

Google投稿文は、短い告知文ではなく、読み手が店舗の雰囲気や利用シーンを想像できる、読み応えのある紹介文にしてください。

## 出力形式

以下の順番で出力してください。

1. 店舗名
2. 日本語の投稿文
3. 区切り線
4. 英語の投稿文

日本語の投稿文は、冒頭に画像キャッチコピーと連動した見出しを入れてください。

例：
＼新浦安で出会う、彩り豊かなスペインの一皿／

## 日本語投稿文の構成

次の流れを基本に、投稿テーマや店舗に合わせて自然に組み立ててください。

1. 季節や時期に合わせた導入
2. 店舗の場所、アクセス、入居施設などの紹介
3. 店舗で楽しめる料理や商品の魅力
4. 食事の楽しみ方や、誰とどんな場面で利用できるか
5. ランチ、ディナー、買い物の前後、仕事帰り、休日などの利用シーン
6. 地域や料理ジャンルを探している人に向けた自然な案内
7. 来店・予約などの締めくくり

## 文章の長さとトーン

- サンプルと同じくらい、店舗や過ごし方が伝わる十分な長さにする。
- 日本語本文は、Googleの最新仕様の文字数制限内で、目安として700〜1,000字程度を基本とする。
- 文字数の上限が異なる場合は、最新の公式仕様を優先し、伝える内容を整理して収める。
- 1段落を長くしすぎず、スマートフォンでも読みやすく改行する。
- 丁寧で親しみやすく、来店を自然に後押しする文体にする。
- 絵文字は文章の流れに合わせて適度に使う。各段落に機械的に付けない。
- 同じ魅力や表現を繰り返して文章を長くしない。
- 検索キーワードは自然に含め、不自然な羅列をしない。

## 季節・店舗情報の扱い

- 季節の表現は投稿予定日と地域に合わせる。
- 投稿時期が分からない場合や、長期間使う投稿の場合は、季節限定の表現を避ける。
- 営業時間、駅からの距離、施設名・階数、価格、予約条件、販売期間などは、登録された情報だけを使う。
- 「駅すぐ」「徒歩○分」「施設の○階」などは、正確な情報が登録されている場合だけ記載する。
- 料理の味、素材、香り、食感、盛り付けなどは、メニュー情報や提供された写真など、根拠が確認できる場合に限って表現する。
- 未登録の特徴、サービス、設備、価格、キャンペーンを創作しない。
- 不足情報がある場合は文章に補わず、公開前の確認事項として表示する。

## 英語投稿文

- 日本語投稿文の内容をもとに、自然な英語で作成する。
- 日本語を一文ずつ直訳せず、英語で読みやすい表現に整える。
- 店名、場所、料理ジャンル、利用シーンなどの重要情報は日本語と一致させる。
- 日本語にない商品、サービス、営業時間、特典などを英語側で追加しない。
- 英語文は日本語より簡潔にしてよい。ただし、店舗の魅力と来店案内は残す。
- 英語文にも、投稿時期や地域に合わない季節表現を入れない。

## 生成後の確認

出力の最後に、担当者向けの確認欄を設けてください。

- 使用した店舗名・店舗ID
- 使用した季節表現
- 投稿文に使用した商品・価格・アクセス情報
- 日本語本文の文字数
- 英語本文の文字数
- 要確認事項

顧客に見せる投稿本文と、担当者向けの確認欄は分けて表示してください。
