# 請求管理・請求書作成ツール 設計・仕様

既存の「Four Seasons 業務アシスト」（`app/`）に「請求管理」メニューとして追加しました。店舗マスタ（店舗・案件）、操作履歴、バックアップの仕組みは既存のものを共用します。

## 1. 調査結果

| 項目 | 結果 |
|---|---|
| 開発環境 | ブラウザだけで動く静的Webアプリ（サーバー不要・インストール不要）。データはブラウザ内（localStorage／添付は IndexedDB）に保存 |
| リポジトリ | `app/`（業務アシスト：広告レポート・議事録・インフルエンサー候補選定）、`index.html`（別資料）。**「新規請求書」フォルダや既存の請求書ファイルはリポジトリ内にありません**（嶋野さんのPC上にあると思われます）。ツールはそれらに一切触れません |
| 既存機能で再利用 | 店舗・案件マスタ、操作履歴、承認画面・確認画面の部品、CSV読み込み、バックアップ |
| 外部サービス連携 | 未設定（APIキー・認証情報なし）。下記の通りCSVで受け渡す構成 |
| テスト環境 | Node.js の単体テスト、Playwright（Chromium）による画面の通し確認、pdftotext によるPDFの文字確認 |

- **過去の請求書は書き換えない**：明細は作成時に契約から複写し、発行時に発行者・税設定・金額を請求書に固定します。契約・設定を変更しても発行済みの請求書は変わりません。
- 表示上の状態（下書き・確認待ち・承認済み・発行済み・一部入金・入金済み・期限超過・取消）は、請求書の状態と入金記録から自動で判定します。

## 4. 計算・チェックの方法

- 金額：明細ごとに 数量×単価（1円未満が出る入力はエラー）。税率ごとに対象額を合計し、**消費税額の端数処理は1枚の請求書につき税率ごとに1回**。税抜／税込は請求書ごとに選択
- 端数処理（切り捨て・四捨五入・切り上げ）は**初期値なし**。設定するまで金額を確定できません
- 日割り：契約で「日割りする」を選んだ場合のみ、月額×利用日数÷その月の暦日数。端数処理は設定で指定。未設定の契約が月の途中で開始・終了するとエラー
- 支払期限：請求先の支払条件から計算（翌月末／○か月後の月末／○日後）。未設定なら手入力
- 請求書番号：形式（初期例 `INV-{YYYY}{MM}-{SEQ3}`）に従い、発行時に既存番号（取消済みを含む）と重ならない番号を割り当て。番号は再利用しません

| チェック | 種類 | 内容 |
|---|---|---|
| 未設定 | エラー（確定不可） | 宛名、発行日、支払期限、明細、単価、税区分、税抜／税込、端数処理、発行者名、振込先、適格請求書の扱い、登録番号（適格請求書の場合）、未確認の税区分 |
| 二重請求 | 警告 | 同じ契約・同じ対象月の、取消以外の請求書がある |
| 期間外 | 警告 | 請求期間外、契約開始前、契約終了後 |
| 請求停止 | 警告 | 契約の請求停止期間・契約終了、請求先が取引停止中 |
| 前払い重複 | 警告 | 前払い済み期間に含まれる月の請求 |
| 請求漏れ | 一覧表示 | 請求対象の契約に請求書が無い月（ホーム・まとめ作成画面） |

警告は、理由を記録するまで承認・発行・一括処理ができません。

## 5. 操作・承認ルール

確認画面（チェックを入れるまで確定ボタンが押せない）を表示する操作：請求書の承認・発行・取消・再発行、送付メール文面のコピー、催促文のコピー、契約の一括変更、CSVの一括取込（入金・既存請求書）、削除（下書き・請求先・契約）、入金登録、税・インボイス設定の変更、ファイル保存。

- このツールは**メールを送信しません**。発行済みの請求書について、送付メールの文面をコピーするだけです（PDFは担当者がメールに添付）
- 催促文は 下書き → 確認待ち → 承認 の後にだけコピーでき、送信は担当者が行います
- 取消・再発行・入金の取消には理由が必須。記録は消さずに残します

## 6. ファイル・データの取り扱い

- 保存先フォルダを指定できます（Chrome・Edge の機能）。**既存のファイルは上書きせず**、同名があれば「(2)」等を付けた名前で保存し、保存前に保存先とファイル名を確認します
- 保存先が未指定の場合は、確認のうえブラウザの「ダウンロード」に保存します（既存ファイルへは書き込みません）
- PDFは印刷画面で保存先を選びます（ファイル名の初期値：`請求書_番号_宛名`）
- 既存請求書のCSV取込・入金CSV取込は、取込前に対象ファイルと各行の結果（取り込む／エラー）を確認できます
- パスワード・APIキー・ネットバンキングの認証情報は扱いません（振込先として請求書に記載する口座情報のみ保存）
- バックアップ：業務アシストの「設定 → バックアップを書き出す」（JSON）。CSV出力：請求一覧・請求明細・会計ソフト取込用（汎用）・入金一覧

## 7. 法令・税務（要確認事項）

> この開発環境からは国税庁のサイトを直接開けなかったため、以下は検索で確認できた情報と一般的な理解に基づきます。**法令対応をうたう前に、国税庁の最新情報と税理士への確認が必要です。**

適格請求書の記載事項（国税庁の資料・各社解説で確認できた範囲）と、ツールでの対応：

| 記載事項 | ツールでの扱い |
|---|---|
| 発行者の氏名・名称と登録番号 | 設定の発行者名・登録番号（T＋13桁、確認状況が「登録を確認済み」の場合のみ適格請求書として発行可） |
| 取引年月日 | 発行日と、明細ごとの対象月（サービス提供月）を記載 → **記載方法が要件を満たすか要確認** |
| 取引内容（軽減税率の対象である旨） | 品目・内容。軽減税率の区分の明細に「※」と注記 |
| 税率ごとに区分した対価の額（税抜または税込）と適用税率 | 税率ごとの対象額と税率を記載 |
| 税率ごとに区分した消費税額等 | 税率ごとの消費税額を記載。端数処理は税率ごとに1回 |
| 交付を受ける事業者の氏名・名称 | 宛名 |

**税理士等に確認が必要な事項**
1. Four Seasons が適格請求書発行事業者として登録済みか、登録番号
2. 各サービスの税区分（課税・非課税・不課税）と税率
3. 消費税の端数処理（切り捨て・四捨五入・切り上げ）の方針
4. 契約の料金が税抜か税込か（契約書・見積書の記載）
5. 日割り計算の方法と端数処理（契約に記載がある場合はそれに従う）
6. 取引年月日の記載方法（対象月の記載で足りるか）
7. 前払い・複数月一括請求の売上計上と請求書の記載方法
8. 振込手数料の負担の記載（請求書の定型文「振込手数料は貴社にてご負担ください」は契約と合わせて要確認）
9. 請求書の控えの保存方法・保存期間（PDFの保存場所、電子帳簿保存法への対応）

情報源：
- [適格請求書の記載事項（国税庁 Q&A）](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/01-09.pdf)
- [インボイス制度 応用編（国税庁）](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/0023011-048_03.pdf)
- [適格請求書等保存方式の概要（東京国税局）](https://www.jfa.maff.go.jp/j/keiei/zeisei/attach/pdf/invoice_setumeikai-10.pdf)
- [インボイス制度請求書の書き方・6つの記載事項](https://www.fastaccounting.jp/blog/20230313/11155/)

## 8. 外部連携（調査結果と提案）

| 連携先 | 調査結果 | 現在の対応 | 提案 |
|---|---|---|---|
| freee会計 | 公開REST APIあり（会計・請求など）。CSVは「取引CSV」形式で取込（UTF-8） | 汎用CSV（取引日・番号・取引先・科目・税区分・税率・税抜・税額・税込） | 利用中の会計ソフトが決まれば、その取込形式に合わせた専用CSVを追加 |
| マネーフォワード クラウド会計 | APIあり。仕訳帳インポート（UTF-8） | 同上 | 同上 |
| 弥生会計 | 公開APIは限定的。CSV（弥生インポート形式・Shift_JIS固定） | 同上（UTF-8のため、そのままでは取り込めない可能性） | 弥生を使う場合はShift_JIS出力を追加 |
| メール | — | 送付文面・催促文のコピーのみ（送信しない） | 送信機能を付ける場合も、承認後・担当者操作のみとする |
| 銀行の入出金明細 | 銀行ごとに形式が異なる | 入金CSV（請求書番号・入金日・入金額）で取込 | 利用銀行の明細CSVに合わせた変換を追加 |

情報源：[請求書データを会計ソフトに取り込む方法（freee・マネーフォワード・弥生）](https://echoinvoice.jp/knowledge/accounting-software-import)、[freee・マネーフォワード・弥生の比較](https://start-link.jp/hubspot-ai/dx/cloud-accounting/cloud-accounting-software-comparison)、[freee：CSVテンプレートの各形式の仕訳ファイル](https://support.freee.co.jp/hc/ja/articles/14687912396825)

## 9. 実装前の確認事項（嶋野さんへ）

1. 適格請求書発行事業者の登録の有無と登録番号
2. 消費税の端数処理の方針、日割りの扱い
3. 各契約の料金（税抜／税込）・税区分・請求開始月・請求タイミング（当月請求／翌月請求）
4. 請求先ごとの支払条件（翌月末払い等）
5. 振込先口座（請求書に記載するもの）
6. 請求書番号の形式（現在の番号の付け方に合わせる）
7. 使っている会計ソフト（CSV形式の決定）
8. 1社が複数店舗を持つ場合、請求書を店舗ごとに分けるか、まとめるか
9. 既存の請求書（「新規請求書」フォルダ）の形式（Excel・PDF等）と、取り込みたい範囲
10. 請求書のレイアウト（社印・ロゴの要否）
