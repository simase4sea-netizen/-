## 4. 候補の探し方

1. **検索結果の手動登録**：担当者がInstagram・TikTok・YouTube・Googleで地域・駅名・料理・ハッシュタグを検索し、見つけたプロフィールURLを貼り付けてまとめて登録。検索した場所・検索語・検索日・記録者を出典として保存
2. **手動登録**：プロフィールURLから SNS・アカウント名を自動で読み取り、残りを入力
3. **CSV一括登録**：ひな形CSV（候補者データベース画面からダウンロード）に記入して取り込み。重複・URLなしの行は登録しない
4. **絞り込み**：キャンペーン画面で、キーワード（地域・駅名・料理・商品・ハッシュタグ）、SNS、起用状況、総合点、「地域が合う」「ジャンルが合う」「目的・SNS・形式が合う」「判定材料不足を隠す」

重複検出：プロフィールURLを正規化（http/https、www/m.、末尾の/、?igsh= 等を除去、大文字小文字を無視）し、同じアカウントは登録不可。表示名・アカウント名が同じで SNS が違うものは「同一人物の別アカウントの可能性」として表示し、関連付けできます。

## 5. 評価方法

6つの観点を0〜100点で評価し、**評価できた観点の重みだけで加重平均**します。未確認の観点は0点にしません。

| 観点 | 初期の重み | 自動評価のルール | 未確認になる条件 |
|---|---|---|---|
| 地域との適合性 | 25 | 活動地域が来店可能エリアと一致100／同じ市区町村80／同じ都道府県50／それ以外15 | 活動地域が未入力 |
| 店舗・料理ジャンル | 20 | 発信ジャンル・ハッシュタグと店舗ジャンル・料理・商品の一致：2語以上100／1語70／一般的なグルメ発信40／不一致15 | 発信ジャンル・タグが未入力 |
| 投稿の反応 | 15 | 反応率（平均反応数÷フォロワー数）・再生率を目安表で点数化。ばらつき（変動係数>1）は−10 | フォロワー数、または直近投稿3件以上の反応・再生数が無い |
| コンテンツ品質 | 15 | 担当者の5段階評価×20 | 未評価 |
| キャンペーン適合 | 15 | 希望SNS・希望投稿形式・目的（動画素材→動画投稿、来店促進→地域70点以上）の一致の平均 | 照合できる情報が無い |
| 起用条件・費用 | 10 | 無料招待で受けられる100／予算内100／予算上限未入力60／無料招待なのに有料20／予算超過10 | 料金が未確認 |

- **フォロワー数だけでは評価しません**（反応数・再生数がそろうまで「投稿の反応」は未確認）
- **判定材料不足**：評価できた重みの割合が60%未満、または評価できた観点が4つ未満。点数は「参考値」として小さく表示し、一覧では後ろに並べます
- **推定値**は「推定」と表示し、推定値を使った評価には「推定値を含む」を表示
- 各観点は候補ごとに**担当者評価（0〜100点・理由必須）で上書き**でき、評価者と日付を記録
- 評価結果には、候補にした理由・懸念点・追加確認事項（広告表記の確認を含む）を文章で表示
- 重み・目安・基準は「評価の設定」で変更可能（変更は操作履歴に記録）。反応率の目安の初期値は**仮の値**です。実績に合わせて調整してください

## 6. 起用までの流れ

1. キャンペーンを作り、条件を入力（店舗は必須）
2. 候補者を登録（検索結果の貼り付け／手動／CSV）→ 各候補の数値・品質を確認して入力
3. 「候補の評価・絞り込み」で起用状況を「候補」「優先候補」に変更、必要に応じて比較
4. 「提案リスト出力」で内容を確認 → 確認待ち → 承認 → CSV・PDF（印刷）で店舗へ提案（承認前は「下書き・社内検討用」と表示）
5. 候補の詳細で連絡文の下書きを作成（起用状況は「連絡文作成」に）→ 確認待ち → 承認 → 送信用にコピー → **担当者が宛先を確認して手動で送信** →「送信済み・完了」で「連絡済み」に
6. 返信あり → 条件確認中 → 起用決定（条件合意の確認画面あり）→ 来店済み → 投稿確認済み（メモ欄に来店日・投稿URL）

## 8. 広告表記（PR表記）について

- 2023年10月1日から、一般消費者が事業者の表示であることを判別しにくい表示（ステルスマーケティング）は景品表示法の不当表示に指定されています。処分の対象は広告主（事業者）です
- ツールでは、評価の「追加確認事項」、提案リストの承認時、連絡文の承認時に、広告表記の確認を表示します。連絡文の下書きには表記のお願いを入れています
- 運用基準や各SNSの表示機能（タイアップ投稿、プロモーション表示など）の詳細は変わることがあるため、**起用前に消費者庁・各SNSの公式情報を担当者が確認**してください（この環境からは消費者庁サイトを直接確認できませんでした）

情報源：[景品表示法（消費者庁）](https://www.caa.go.jp/policies/policy/representation/fair_labeling/)、[景品表示法における不当表示にステルスマーケティングが追加されました](https://www.tokio-dr.jp/publication/column/098.html)

## 10. 自動選定（地域・フォロワー数・ジャンル）— 追加

設定（APIキー等）以外は自動で動くようにしました。

### 自動で行うこと
1. **探す**：キャンペーンの「来店可能エリア・所在地」×「店舗ジャンル・料理」から検索語を作り、YouTube Data API で動画を検索（緯度経度と半径を入れると位置情報付き動画も対象）
2. **取り込む**：見つかったチャンネルの登録者数・直近動画の再生数／高評価・コメント数・投稿頻度を取得し、候補者として登録（既存なら更新）。取得元「YouTube Data API」と取得日を自動記録
3. **他SNSをつなぐ**：チャンネル説明に書かれた Instagram・TikTok のアカウントを、同一人物の別アカウントとして登録。Instagram は Business Discovery でフォロワー数・直近投稿の反応を取得
4. **判定する**：公開テキスト（チャンネル説明・動画タイトル・プロフィール・投稿文）から地域・ジャンルを判定（根拠の文を保存）。フォロワー数はキャンペーンの下限・上限と比較
5. **選ぶ**：3条件（地域・フォロワー数・ジャンル）をすべて満たし、判定材料不足でない候補を評価点順に並べ、上位を「優先候補」、残りを「候補」に自動で設定
6. **下書きを作る**：優先候補には連絡文の下書きを自動作成
7. **繰り返す**：アプリやキャンペーンを開いたとき、更新間隔（初期7日）を過ぎていれば自動で再実行。条件を変えたら次に開いたときにやり直し

### 自動で行わないこと（理由）
| 内容 | 理由 |
|---|---|
| DM・メールの送信 | 各SNSの規約・誤送信防止のため。承認後に担当者がコピーして送る |
| TikTok の検索・数値取得 | 商用で使える公式の検索・他人のアカウント取得APIがない（研究用APIは学術・非営利のみ） |
| Instagram のハッシュタグ・地域からの発見 | 公式APIのハッシュタグ検索は投稿者のアカウント名を返さない。アカウント名が分かれば Business Discovery で取得可能（ビジネス・クリエイターアカウントのみ） |
| Google 検索での発見 | Google の Custom Search JSON API は新規受付終了（2027年1月1日に提供終了予定） |
| スクレイピング・ログイン回避・自動フォロー/いいね | 規約違反のため行わない |

### 手動との関係
- 担当者が起用状況を手で変えた候補は、以後の自動選定で変更しません（「手動で設定」と表示）
- 手で入力した活動地域・ジャンルは自動判定で上書きしません。品質評価・料金・連絡先・メモも変更しません
- 判定の根拠（どの動画・投稿の文に地域名・ジャンル名があったか）は候補者の画面に表示
- キャンペーンが無くても、プロフィール・投稿文に出てくる都道府県名・主な市区町村や繁華街名（例：渋谷・恵比寿→東京都、高松・瓦町→香川県）から**大まかなエリア**を推定し、候補者一覧に「香川県（高松・瓦町）［推定］」のように表示します。人名と紛らわしい県名（石川・長野など）は「県」が付いた場合のみ数えます。投稿の位置情報タグは公式APIで取得できないため使いません。手がかりが無い場合は「未確認」のまま（推測で補いません）

### 必要な設定（「評価の設定」画面の下部）
| 項目 | 取得方法 | 備考 |
|---|---|---|
| YouTube Data API キー | Google Cloud でプロジェクトを作り、YouTube Data API v3 を有効化してAPIキーを発行 | 1日10,000ユニット（検索1回100、取得1回1）。初期設定（検索語4つ）で1回あたり約410ユニット |
| Instagram アクセストークン・自社のInstagramビジネスアカウントID | Metaの開発者アカウントでアプリを作成（ユースケース「Instagramでメッセージとコンテンツを管理」・Facebookログイン）。グラフAPIエクスプローラで instagram_basic・instagram_manage_insights・pages_show_list・pages_read_engagement・business_management を付けてユーザートークンを発行し、アクセストークンデバッガーで延長（約60日） | トークンには有効期限があり、更新が必要。取得できるのはビジネス・クリエイターアカウントのみ |

### 確認方法

## 11. URLの一括登録 — 追加

キャンペーンの「2. 候補の評価・絞り込み」または「候補者データベース」の **「URLを一括登録」** から使います。

1. プロフィールURLを貼り付ける（1行に複数・名前やメモが混ざっていても可。`@アカウント名` だけなら Instagram として扱う。`?igsh=` などの付加情報は自動で除去）
2. 確認画面で、新規・登録済み・登録しないもの（投稿や動画のURL、対応外のURL、同じURLの重複、読めない行）を理由付きで確認して登録
3. 登録後、設定済みの公式APIで自動取得（Instagram：Business Discovery／YouTube：チャンネルの@ハンドルから取得）。取得できないもの（個人アカウント、TikTok・X、APIの設定が無い場合）は数値が「未確認」のまま
4. キャンペーンから登録した場合は、3条件（地域・フォロワー数・ジャンル）で自動選定し、優先候補・候補に振り分け

入手経路のメモは「取得元」として候補者ごとに保存し、更新履歴に残します。
